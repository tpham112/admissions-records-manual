# Transcript Evaluation — Transfer Units

## Overview
This section provides guidelines and procedures for evaluating transfer units from other institutions. It covers the steps for processing total transfer units, including scanning transcripts, entering data into the IASU and EXTS systems, and updating the STAC records.

## Total Transfer Evaluation

### Accreditation

We cannot evaluate transfer units from institutions that are not accredited. Ensure that the institution is recognized by a legitimate accrediting body before proceeding with the evaluation.

- Check the institution's accreditation by visiting Transfer Evaluation System (TES)
