# Calculating Transfer Units

[← Transfer unit scenarios and verification](transcript-transfer-unit-scenarios.md) · [Transcript overview](transcript-overview.md)

1. Sum all the units for courses that are eligible for transfer credit.
    - You can find a cheat sheet [here](https://rsccd.sharepoint.com/:x:/s/Admissions2/IQAJYeNdOTO3TpPQ44pOwSBGAb04PCdcgoNhhND5AlGWmdE?e=hGWJLa).
    - Exclude any units for non-degree applicable courses and in progress courses.
    - Include units for repeated courses only in the UNITS ATMPT column as per the institution's transcript key.
    - Verify the total transfer units against the student's transcript and the catalog review to ensure accuracy.
