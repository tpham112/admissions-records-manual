# 1098-T SSN/ITIN Solicitation Form

**Tags:** 1098-T · SSN · ITIN · Colleague · ARI

---

## Overview

Use the documentation submitted in response to an SSN/ITIN solicitation to update the student's SSN on file in Colleague.

---

## Processing Steps

1. Review the submitted SSN/ITIN solicitation documentation and confirm that it includes a number to use. The documentation does **not** need to be signed.
2. In **Colleague**, navigate to the student's **BIO** screen.
3. Update the SSN on file to the number provided in the documentation.
4. Click **Save All**.
