# Logging Transcripts and Test Scores in IASU

## Steps

1. Go to **IASU** and search for the institution where the transcript comes from.
    - **If it is not in IASU,** add it on a new line and choose the school code that matches the name and address on the transcript legend.
    - **If it is in IASU,** continue below.

2. **If a transcript from this institution has been evaluated before,** check STAC for the evaluation date and timestamp.
    - If a timestamp exists, locate the scanned evaluated transcript in Laserfiche (LF).
    - If no timestamp exists, try to match the transfer units in STAC with the evaluated transcript in LF.
    - Compare all transfer units against the new transcript.
    - If all units match with no changes, select `(DUPL)` for Status and stop.
    - If there are changes, update Start/End dates and select `(RECD)`.

3. Log the transcript using the fields below.

## Field Reference

| Field | What to Enter |
|-------|---------------|
| **Transcript type** | Pick the code that applies: College / High School / International transcript / External exams (AP/IB/CLEP Scores) |
| **Date received** | Current date |
| **Status** | `RECD` — Official Received |
| **Year attended** | Year of first and last term attended |
| **Start/End dates** | No longer need to enter |
| **Acad Credentials** | Enter if Associate's or Bachelor's degree is found on transcript |
| **Comment** | Timestamp + note (use one of the source codes below) |

### Semester Date Codes

| Semester | Start Date | End Date |
|----------|-----------|----------|
| Summer | 06/01/YY | 07/31/YY |
| Fall | 08/01/YY | 12/31/YY |
| Intersession / Spring | 01/01/YY | 05/31/YY |

### Comment Source Codes

Use one of these codes in the comment:

- `Parchment`
- `XAP`
- `adm email`
- `counter`

### Degree Entry

1. Drill into the degree box and open the degree date field.
2. Type `...` (three dots) to open the degree-code selection.
3. Select the appropriate degree code and click **Open**.
4. Enter the date the degree was earned.
5. Click **Save** once, then click **Update**.

---

## Important Notes

!!! warning "Multiple Entries"
    Make sure to click on **1** and **Insert a new line** if there are already entries — do not overwrite existing records.

### District Transcripts with Multiple Institutions
If you receive a transcript from a school district with multiple institutions, **add all institutions the student attended** to IASU. Refer to the transcript legend for school codes.

Common district transcripts include:
- Riverside Community College District
- Los Angeles Community College District
- San Diego Community College District
